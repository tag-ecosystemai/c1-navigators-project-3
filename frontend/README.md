# Credence — Credit Intelligence Investigation Agent

Frontend MVP built directly from the supplied PRD.

## Scope
Application Investigation, Financial Analysis, Transaction Investigation, Lending Policy Check, Risk Assessment, and Investigation Report.

Primary user: Credit Analyst. Secondary user: Credit/Risk Supervisor.

Risk assessment is supporting information; final lending decisions remain human decisions.

## Run
npm install
npm run dev

All data is synthetic. Backend integration can replace `src/data.ts` with FastAPI service calls.
